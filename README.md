# Dicionário Git

Este repositório tem como objetivo **auxiliar no aprendizado de versionamento de código utilizando Git e GitHub.**
O conteúdo foi organizado com base em **comandos e situações comuns do dia a dia**, começando pelos conceitos fundamentais para iniciantes e avançando gradualmente para situações envolvendo **branches e trabalho em equipe**.
